# Spec — 求解内核（src/solver）

## 要构建什么

- **目标**：把用户写的一段模型文本，转换为「各变量取值 + 目标值 + 诊断信息」，且结果在数值上绝对精确、在语义上绝对诚实（不确定时必须说出来，不能给一个看似合理的答案）。
- 内核是纯函数集合，不含任何 React / DOM 依赖，可脱离界面独立测试与复用。

## 行为

### 支持的模型形态

| 形态                        | 行为                                                |
| --------------------------- | --------------------------------------------------- |
| 只有等式，解唯一            | 返回唯一解                                          |
| 只有等式，解不唯一          | 返回一个可行点，并说明「尚缺 N 个条件」与自由变量名 |
| 等式自相矛盾                | 返回 infeasible，指出矛盾行（`0 = 非零`）           |
| 等式 + 不等式 + 边界        | 返回满足全部约束的一个解                            |
| 有目标函数                  | 返回最优解与最优值                                  |
| 目标无界                    | 返回 unbounded，提示补充上限约束                    |
| 含整数 / 二元变量           | 走分支定界，返回值必为整数                          |
| 含二次项，因子为整数 / 二元 | 精确线性化（big-M / 二进制展开），结果精确          |
| 含二次项，连续 × 连续       | 空间分支定界，返回近似解 + 可证明的损失率上界       |

### 语法

```
语句      := 变量声明 | 常量赋值 | 目标函数 | 约束
变量声明  := name ":" [free] 类型 [bounds]     # 份数 : 非负整数 <= 40
常量赋值  := name ":=" 表达式                  # 单价 := 34 / 10
目标函数  := ("max"|"min") 表达式              # max 大 * 100 + 小 * 18
约束      := [label ":"] 表达式 比较符 表达式   # 预算 : 34*x + 42*y <= 849
```

- 一行一条语句；`#` 与 `//` 为行注释。
- 表达式支持 `+ - * / ^`、括号、隐式乘法（`2x`、`3(a+b)`、`x y`）。
- 变量名可用中文；全角数字与符号自动归一化为半角（1:1 映射，列号不失准）。
- 类型别名：`实数` / `整数` / `非负` / `非负整数` / `正整数` / `自然数` / `二元`（含英文同义词）。
- 常量必须先定义再使用，可引用更早定义的常量。

### 二次项

- 支持 `x * y` 与 `x^2`（视为 `x*x`），不接受三次及以上相乘。
- **A 类**：至少一个因子是整数 / 二元变量。二元因子用 4 条 big-M 约束；
  整数因子用二进制展开（`x = L + Σ2^k b_k`，`Σ2^k b_k ≤ U-L`），逐位 big-M。
  产物是纯线性 MILP，结果**精确**。
- **B 类**：两个因子都是连续变量。用空间分支定界 + McCormick 包络求近似解，
  `Solution.approximation.relativeGap` 给出损失率的**可证明上界**。
  B 类要求模型有目标函数、且乘积因子有有限上下界；否则明确拒绝。
- 参与乘积的变量缺边界时，先对线性松弛跑 LP 反推（FBBT），仍无界则报错并给出声明示例。

### 拒绝的输入

必须抛错并说明原因，**不得**近似求解后当精确解返回：

| 输入                                                | 行为                 |
| --------------------------------------------------- | -------------------- |
| 三次及以上变量相乘（`x * y * z`）                   | 拒绝：次数超过 2     |
| 变量的三次及以上幂（`x^3`）                         | 拒绝：次数超过 2     |
| 变量做除数（`1 / x`）                               | 拒绝：非线性         |
| 含未知量的 `ceil` / `floor` / `abs` / `max` / `min` | 拒绝：非凸           |
| `!=` 约束                                           | 拒绝：可行域非凸     |
| 连续 × 连续且无目标函数                             | 拒绝：无法界定损失率 |
| 变量重复声明、常量重复定义、两个目标函数            | 拒绝：模型语义错误   |
| 空的取值范围（下界 > 上界）                         | 拒绝                 |

常量参数上的取整函数应折叠求值（`ceil(5.3)` → `6`）。

## 输入 / 输出

- **输入**：`source: string`（模型文本）；可选 `{ integer?: boolean; gapTolerance?: Frac }`
  —— `gapTolerance` 是 B 类二次项的相对损失率阈值（默认 1%）。
- **输出**：`Solution`
  - `status`：`optimal` / `infeasible` / `unbounded` / `degenerate`，附 `reason`
  - `values`：变量名 → `Frac`（不含内部辅助变量）
  - `objectiveValue?`：`Frac`
  - `approximation?`：`{ relativeGap: Frac }`，仅 B 类二次项出现；UI 必须据此标注近似值
  - `constraintReport?`：每条约束的余量、是否取等、是否满足、行号
  - `warnings`：语义提示（**必须自带行号**，因为它是纯字符串数组）
  - `stats`：变量数、约束数、整数变量数、搜索节点数
  - `varOrder`：变量展示顺序（按模型中首次出现次序，非字母序）
  - `objectiveSense?`：`max` / `min`
- **错误**：抛 `SolverError` 子类（`ParseError` / `ModelError` / `NumericError`），携带 `line` / `col`。`message` 只描述语义，不含位置。

## 约束

1. **数值全程精确**：只用 `Frac`（BigInt 分子 / 分母）。`number` 仅允许出现在展示层，求解链路里出现 `parseFloat` / `Number()` 即为缺陷。
2. **`Frac` 不变量**：`d > 0`、`gcd(|n|, d) === 1`、零统一为 `0/1`。
3. **`Frac.parse` 不经 `number`**：走字符串十进制解析，因此 `parse('0.1')` 精确等于 `1/10`。
4. **位置信息只在结构化字段**：`line` / `col`；`describe()` 生成完整文本。`warnings` 例外，必须自带行号。
5. **不得吞错**：任何失败都要冒泡到调用方。非 `SolverError` 的异常由 UI 显示为「内部错误」。
6. **求解路径唯一**：实际解一律由 MILP / LP 给出；高斯消元只做诊断（区分唯一 / 无穷多 / 矛盾）。避免两套可行性判定互相漂移。含二次项时由 `bilinear.ts` 分流：全 A 类仍由 MILP 出解，含 B 类由 `spatialbb.ts` 出解；非线性下跳过高斯诊断与唯一性探测。
7. **算法终止性**：单纯形用 Bland 规则（可证明不循环），并设迭代上限；分支定界设节点上限 200,000；空间分支定界设节点上限 10,000 与 3 秒墙钟预算。超出时报 `degenerate` 或带 gap 的近似解，不挂死。
8. **近似必须可证明**：B 类二次项返回的 `relativeGap` 是损失率上界；不得把无保证的启发式值标记为 `optimal` 而不给 gap。

## 边界条件

- **空模型**：抛错「模型为空」，不返回空解。
- **无变量**（只有常量表达式）：正常求解。
- **`b < 0` 的约束行**：整行取反并翻转不等号方向后再进单纯形。
- **冗余约束**（整行全零）：标记为不可进基，第二阶段忽略。
- **整数变量的非整数边界**：下界收紧为 `⌈L⌉`、上界收紧为 `⌊U⌋`。收紧后平移量必为整数，分支定界判分数才成立。
- **实数变量的严格不等式**：放宽为闭区间 + warning（开集无最值）。
- **整数变量的严格不等式**：精确收紧（`x < 5` → `x <= 4`），语义等价，无需 warning。
- **目标函数含常数项**：还原公式为 `obj = (minimize ? r : -r) + C`，其中 `C` 取**原始符号**不随 max/min 翻转。
- **变量数 > 40**：跳过唯一性探测（代价 2n 次求解），给出其中一个解并提示。
- **唯一等式解违反边界 / 整数约束**：报 infeasible，并补充说明「等式部分本身有唯一解 X，但它违反了不等式 / 边界 / 整数约束」。
- **最优解不唯一的探测**：必须先把「目标值 = 最优值」锁成等式，在该切面上逐变量求 max/min。否则变量只要能动就会误报——那些变动会改变目标值，并非最优。
- **二次项因子无界**：先做 FBBT 反推；仍无界则报错，并给出「`x : 非负 <= 100`」这类可操作的声明示例。
- **连续 × 连续且无目标函数**：报错，建议补 `max` / `min`，或把因子声明为整数以走精确路径。
- **B 类超出节点 / 时间预算**：有可行解时返回当前最优解 + 当前 gap；无可行解时报 `degenerate`，绝不挂死。

## 完成定义

- 上表全部数字可复现，且 `tests/e2e/qq-farm.test.ts` 中每个断言都注明了它在文档中的出处。
- 文档中两处中途舍入的偏差被**明确标注**而非静默沿用：
  - 「等待 29.74 分钟」→ 精确值 29.75（文档先把 `11.9/24` 舍成 `0.496` 再乘 60）
  - 「每块 0.496 小时」→ 精确值 `119/240`（`0.495833…`）
- 拒绝仍不支持的非线性时，给出的消息包含原因与出路，不只是「不支持」。
- B 类近似解必须同时满足：`approximation.relativeGap > 0`（若确实未证明最优）、约束核对表全部满足、目标值落在 `真实最优 × (1 - gap)` 的保证区间内。
- 求解结果可被用户自行验证：约束核对表逐条列出余量与是否取等。
