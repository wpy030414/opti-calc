# Spec — 模型编辑器（ModelEditor）

## 要构建什么

- **目标**：让不懂建模语法的人也能顺畅地写下模型、并立刻知道自己哪里写错了。
- 编辑器不是「一个 textarea」：它要同时承担语法反馈（高亮）、位置反馈（行号与错误行）、错误解释（原因 + 下一步）三件事。

## 行为

### 语法高亮

- 透明 `textarea` 叠加在高亮层之上，两层共用字号、行高、内边距与换行策略，因此光标位置与高亮文字始终对齐。
- 滚动由 textarea 驱动，高亮层通过 `onScroll` 跟随。
- 着色类别：注释（灰斜体）、关键字（紫）、数字（琥珀）、运算符（天蓝）、变量名（近黑 / 近白）。
- **按行独立着色**，不做跨行状态机。本语法规定一行一条语句，按行处理既简单又不会出现「前面写错导致后面全乱」的连锁失准。
- 高亮必须与解析器共用同一份规则：注释起始位置来自 `parser.commentStart`，关键字来自 `parser.KEYWORDS`。否则会出现「高亮认为是代码、解析器认为是注释」的不一致。
- Token 正则在模块级复用，使用前必须重置 `lastIndex`（带 `g` 标志的正则有状态）。
- 标识符允许中文：U+0080 以上全部视作字母，覆盖 CJK 与全角字符。

### 行号与错误定位

- 左侧行号栏与模型行数一一对应。
- 出错行：行号染红加粗，该行正文加浅红底，输入层边框转红，`textarea` 置 `aria-invalid`。
- 编辑器下方另有一行完整错误文本：「第 N 行：<语义>」。位置只出现一次——消息文本本身不含行号（见 ADR-008）。
- 空行需要一个占位字符撑住行高，否则行号与内容会错位。
- 高亮层末尾补一行，滚动到最后一行时不会短一截。

## 输入 / 输出

- **输入**：`value: string`、`onChange`、`error?: { line, message } | null`。
- **输出**：受控组件，自身不持有模型状态；错误由上层（`App`）求解后传入。

## 约束

1. 受控组件：`value` 完全由外部决定，内部不缓存文本。
2. 不使用 `contenteditable`——它在跨浏览器行为、光标定位、输入法处理上都不可靠。
3. 输入层文字透明但光标可见（`text-transparent caret-slate-900`），选区高亮需单独给色，否则选中时看不见选了什么。
4. 关闭拼写检查、自动大写、自动更正（`spellCheck={false}` 等）——中文变量名会被拼写检查标红一片。
5. 不引入 CodeMirror / Monaco 等编辑器库：本语法只有一行一条语句，自带高亮约 190 行即可（`ModelEditor.tsx` 实测 187 行），引入重型编辑器会让 bundle 从 405 KB 涨到 1 MB 以上。

## 边界条件

- **空文本**：不报错，结果面板显示「在左侧写下条件后自动求解」。
- **只有注释与空行**：等价于空模型，抛「模型为空」。
- **末行为空**（文本以 `\n` 结尾）：行号栏应包含该空行，与 textarea 的视觉行数一致。
- **超长行**：`wrap="soft"` + `break-words`，两层同步折行。
- **全角输入**：中文输入法下打出的 `＜＝`、`３` 由 lexer 归一化，编辑器不需要额外处理，但高亮应正确识别（Token 正则覆盖 U+0080 以上）。
- **错误行为 0 或超出范围**：不高亮任何行，但仍显示错误文本。
- **求解抛出非 `SolverError`**：上层转为「内部错误：…」并标注第 1 行，不静默失败——否则用户会以为是自己写错了。

## 验收标准

- [x] `tests/component/app.test.tsx`：挂载后 textarea 存在且带默认模型
- [x] 行号数量与模型行数一致
- [x] 第二行出错时显示「第 2 行」——若行号定位失效（永远报第 1 行），该断言会失败
- [x] 错误消息不重复显示行号（断言 `第 1 行：` 存在且 `第 1 行第` 不存在）
- [x] 语法错误时页面骨架仍在（标题与 textarea 都不消失），即不白屏
- [x] `vp check` 零警告

### 尚未自动化验收的项

- 高亮层与输入层的像素级对齐（字体度量、折行位置）——需要真实浏览器截图比对，jsdom 无布局引擎。
- 滚动同步的实际视觉效果——jsdom 不实现滚动。
- 输入法（IME）组合输入期间的行为——jsdom 不支持 composition 事件序列。

这三项需人工在浏览器中确认，见 `README.md` 的运行说明。

## 完成定义

- 用户写下模型时能看见语法着色，出错时能一眼定位到行，且错误文本告诉他原因与下一步。
- 输入过程中无闪烁（防抖由 `App` 负责，编辑器不做节流）。
- 中文变量名、全角符号、省略乘号的写法都能正确高亮与解析。
